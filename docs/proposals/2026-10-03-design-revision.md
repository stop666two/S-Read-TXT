## 3. 架构影响概要

- 新增 Rust 模块（提案）：批量编辑引擎、行操作、序号格式器、多光标、剪贴板历史、多文件搜索、主题装载、导出、快照/版本历史、文件比较、拆分/重命名、文件关联、手动更新、正则超时执行器。
- 前端新增：设置 v2（搜索/分组/导入导出/恢复默认）、主题运行时装载器（单驻留）、欢迎页、命令面板、大纲/书签/滚动条标记、多分屏/多窗口管理、批量操作对话框（预览/进度/取消）、状态栏 v2、i18n 框架、背景图层。
- 数据目录扩展：
  - `data/themes/`（主题文件）、`data/backgrounds/`、`data/snapshots/`（按文件哈希分目录）、`data/backups/`、`data/annotations/`（书签/高亮/批注，按文件哈希）、`data/clipboard-history.json`
  - 配置按模块拆分（settings/reader/shortcuts/editor/ui 等，遵循规则 66 分块管理）
- 设置 schema v2 + 迁移（v1→v2 自动升级；失败回退默认并提示）。
- 现有能力复用：编辑引擎（片表/撤销/保存链）、查找替换（正则框架）、会话/历史、快捷键引擎、虚拟滚动、mmap 读取、CI/CD 全量自检。

## 6. 验收标准修订

- 内存：≤120MB（应用全进程树合计，标准场景＝10×100MiB 只读、单主窗口）。
- 冷启动：<1s 可阅读。
- 安装包：<10MB。
- 功能：对应需求十三 1–11 条逐条验收。
- 每期结束：verify-all 全量自检 + 三条红线复测 + 维护者验收。

## 7. 风险与缓解（摘要）

- 多窗口内存：按需创建、关闭释放；红线口径已确认（另行报告）。
- 批量操作大文件：异步分片+进度+取消+单步撤销；预览先行。
- 主题文件化：单驻留+失败回滚+FOUC 防护（启动先读主题再渲染）。
- 版本历史磁盘占用：双上限+自动清理+设置内可视。
- i18n 回归面：语言包键完整性测试 + 全量 E2E 复跑。
- 文件关联注册权限：安装器选项与便携模式兼容处理。
- 正则超时：自研执行器（分块+截止检查），超时零修改。

## 8. 回滚方案

- 每期开工前 git tag；失败回退 git 并保留上一版安装包。
- 设置 schema v2 迁移失败：备份旧配置并回退默认。
- 主题切换失败：回滚旧主题并提示。
- 批量/拆分/重命名等高风险操作：预览+确认+单撤销步+备份。
