## P0 基础设施与外观

**交付物**
1. 设置系统 v2：可搜索、常用靠前、高级折叠；单项/分组/全部恢复默认；导入/导出（schema 强校验）；schema v2 迁移（v1 自动升级，失败回退+提示）；变更日志记录。
2. 主题系统重构：7 套（跟随系统/浅色/深色/护眼绿/纸张米黄/高对比/极简灰）；文件化（JSON+CSS 变量，data/themes/）、列表仅元数据、按需读取、**单主题驻留**、切换失败回滚、导入/导出、自定义主题；切换动画（可开关、可调时长）；FOUC 防护（启动先读主题再渲染）。
3. 背景图：本地图片、透明度 0–100%、填充模式、模糊度、暗化/亮化；格式/大小/路径强校验；性能模式自动禁用。
4. 欢迎页/空状态改版：打开文件、新建文件（入口）、最近文件、快捷键提示、示例文本。
5. i18n 框架：中英双语、即时切换、语言包结构（当前全部中文文案抽取）。
6. 按需启动与资源策略：启动路径最小化、面板/引擎懒加载、缓存上限框架、磁盘占用可视+清理。
7. 快捷键扩展框架：全部命令可录制、冲突检测、恢复默认、导入导出。
8. 大文件双阈值：只读阈值（默认 100MB）+ 硬上限（默认 2048MB），只读打开提示。
9. 配置位置迁移功能（重启生效）。

**验收标准**
- 全部现有功能在设置 v2/主题重构后无回归（verify-all 全绿）。
- 主题切换：内存中仅一套激活；切换失败自动回滚；无 FOUC；7 套主题视觉经维护者确认。
- 设置迁移：v1 配置无损升级；损坏配置回退默认并提示。
- 中英切换即时生效，无文案残留。
- 三条红线复测通过（内存 120MB 口径、启动 <1s、包体 <10MB 趋势监控）。

**测试增量**
- 主题装载/切换/回滚/单驻留断言（E2E）。
- 设置导入导出/迁移/校验收敛/恢复默认（单测 + E2E）。
- i18n 键完整性检查（lint 级）；中英界面 E2E 快照。
- 背景图校验（格式/大小/权限）。
- 大文件双阈值行为（单测 + E2E）。

**风险与回滚**：主题/设置重构影响面最大；保留旧配置读取兼容与 git 回退点。UI 先行：主题色板与欢迎页先出设计稿经维护者确认后实现。

## P1 编辑批量核心

**交付物**
1. 批量插入/序号（D43）：前/后添加；10 种序号格式；起始/步长/补零/分隔符/后缀；跳过空行/标题行；范围选择（全文/当前行/段落/可见区/选区/行区间/非空行/正则匹配/书签行）；模板变量；预览（行数可调）；执行前边界校验（超范围报错中止）；异步分片（进度/取消/分片大小）；单撤销步；正则条件与捕获组；正则超时保护。
2. 行操作套件（D44）：上移/下移/复制/删除/合并/拆分；排序（字典/自然/长度/随机/反转）；去重（保留首次/末次/忽略大小写/模糊）；去空行/去首尾空白；缩进/反缩进/Tab 空格互转；大小写/全角半角；行首/行尾增删；列编辑/CSV↔TSV；全部支持范围语义与预览/撤销；默认范围、默认参数在设置中可配。
3. 多光标/列选择/矩形编辑（D45）。
4. 过滤视图（仅阅读，D61）。
5. 剪贴板历史 + 复制为纯文本/HTML/Markdown（D47）。
6. 查找替换增强：全词匹配、循环查找、高亮全部/计数、替换预览、范围限定、历史、结果列表、增量搜索、多文件搜索与批量替换（D58）、正则助手/常用正则库/测试面板/捕获组替换。
7. D77 辅助编辑组（待批注后定默认值与触发方式）。

**验收标准**
- 序号全格式边界正确（①/❶ ≤20、罗马 ≤3999、中文大数不静默错误；超范围预览报错中止）。
- 范围语义正确（手动选区优先等）；模板变量非法值有提示。
- 批量操作：预览、可取消、单步撤销；100MB 文件批量不卡死（异步+进度）。
- 正则超时：中断且零修改，提示文案逐字符合要求。
- 行操作全清单可用、可配置；去重/排序边界正确。
- 多光标/列编辑在虚拟滚动下可用。

**测试增量**
- 序号格式器边界用例集；范围语义矩阵；模板变量校验。
- 行操作属性测试（生成随机文本+操作+不变量断言）。
- 批量性能用例（100MB 异步/取消/进度）。
- 正则超时（构造超时输入）与零修改断言。
- 多文件搜索替换（预览/备份/回滚）。

**风险与回滚**：多光标与列编辑在虚拟化编辑器上复杂度最高，独立子阶段推进并逐子项验收；批量操作默认先预览，任何异常零写入。

## P2 阅读增强

**交付物**
1. 状态栏 v2（D49）：总行数/总字符/总词数/文件大小/编码/换行符/修改状态/只读状态；光标行列与当前行字数；选区范围（A 行 B 字 → C 行 D 字）、选中行数/字符/词数、未选择提示；进度与滚动位置；计数模式（字素簇/码点/字节，默认字素簇）；Tab 宽度（默认 4）；点击项（行列跳转、编码切换、换行符 LF/CRLF/CR 切换）；显示项配置（显隐/排序/计数模式/总词数）。
2. 大纲（内置章节正则+可编辑+预览）、折叠（阅读+编辑双模式）、面包屑。
3. 书签/标记/待办/复选框/行内批注/高亮颜色（持久化 data/annotations/）；滚动条标记（搜索/书签/修改位置）。
4. 导航：跳转指定行/字符偏移、导航历史、返回上一位置。
5. 阅读模式组（D62）：自动滚动、专注、打字机、分页、双页、翻页动画；护眼/休息提醒、番茄钟、阅读时长统计。
6. 进度记忆扩展（D76）：光标、滚动、折叠状态、每文件进度。
7. 显示选项：行号/相对行号/当前行高亮/自动换行/长行横向滚动/标尺/缩进参考线/不可见字符（空格/Tab/换行/行尾空格）。

**验收标准**
- 计数口径标准样例全对（Emoji/组合字符/代理对/全角；字素簇/码点/字节三模式）。
- 状态栏即时刷新（光标/选区/编辑）；点击项行为正确。
- 折叠双模式行为正确；大纲正则可编辑并预览；书签等持久化且可清理。
- 阅读模式与显示选项均可配置、即时生效。
- 大文件下统计异步不卡顿。

**测试增量**
- Unicode 计数标准样例集（字素簇/码点/字节）。
- 状态栏刷新与点击 E2E。
- 折叠/大纲/面包屑 E2E；批注持久化/清理。
- 阅读模式（自动滚动/分页/双页/动画时长）E2E。

## P3 文件与流程

**交付物**
1. 快照/自动保存/崩溃恢复/版本历史（D55/D56）：定时快照、可选写回、崩溃恢复提示、版本查看/恢复、双上限清理。
2. 导出/打印（D54）：TXT/HTML/Markdown、系统打印（含打印为 PDF）。
3. 新建文件（D53）；命令行打开、粘贴打开、文件关联扩展名用户自定义（D51）。
4. 多窗口 + 分屏（最多四栏）+ 跨窗口拖拽标签（D52）；标签颜色。
5. 文件比较/合并、按内容/行数拆分、批量重命名（D57）。
6. 多文件搜索替换（若 P1 未完成则在此完成）与写盘安全（预览/备份）。
7. 会话恢复扩展（D76）：主题、窗口布局、多窗口状态。

**验收标准**
- 崩溃恢复：强杀进程后可恢复至最近快照；版本历史可查看/恢复。
- 导出产物正确（HTML/Markdown 结构+样式）；打印预览可用。
- 多窗口/分屏/拖拽正确；每窗口独立标签组；关闭窗口释放资源。
- 比较/合并/拆分/重命名均有预览+确认+撤销/备份。
- 文件关联注册与便携模式无冲突。

**测试增量**
- 快照/恢复/版本历史 E2E（含强杀模拟）。
- 导出黄金样例（TXT/HTML/MD）。
- 多窗口/分屏/跨窗口拖拽 E2E；分屏数量上限。
- 比较/拆分/重命名（含备份与回滚）单测+E2E。
- 文件关联（安装/卸载注册表）与便携模式核查。

## P4 系统与发布

**交付物**
1. 命令面板（D75）：全功能可搜索执行。
2. 可访问性完善（D74）：高对比叠加开关、减少动画、字体缩放、焦点可见、屏幕阅读器优化。
3. 性能模式、内存监控、缓存清理（D41）。
4. 隐私清除（历史/会话/快照/批注/剪贴板/日志）、崩溃日志、错误报告（本地）、无网络模式（待批注项）。
5. 手动更新检查（D71）：GitHub Releases、应用内下载+SHA256、失败降级弹窗。
6. 全量验收（需求十三逐条）+ 文档更新 + 发布。

**验收标准**
- 需求十三 1–11 逐条通过。
- 三条红线复测报告（120MB/启动/包体）+ 离线核查 + 便携核查。
- a11y 键盘全流程可达；高对比/减少动画生效。
- 更新检查：正常/失败/降级三路径验证；无网络默认无请求。

**测试增量**
- 命令面板检索与执行 E2E。
- a11y 自动化检查（焦点/对比度/ARIA）与人工核对。
- 更新检查桩测试（成功/失败/降级）。
- 隐私清除完整性断言。

## 跨期机制

- UI 先行：每期涉及视觉的界面先出设计稿，经维护者确认后实现（AGENTS.md 145）。
- 每期收尾：`verify-all` 全量自检 + 红线复测 + 构建 + 维护者验收 + git 细颗粒提交。
- 测试基线：现有 22 步自检持续跑；E2E 套件随期扩充。
- 回滚：每期开工前 tag；异常回退至上一 tag 并保留上一版安装包。
