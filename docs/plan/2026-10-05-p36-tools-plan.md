pub struct RenameEntry { pub old: String, pub new: String, pub status: RenameStatus }

pub fn plan(dir: &Path, files: &[String], rules: &RenameRules) -> Vec<RenameEntry>  // 纯计算，不触盘（Exists 判定需扫 dir 列表）

## 风险与对策

- **Myers 最坏复杂度**：d 上限保护 + 前缀后缀裁剪；超限报 DIFF_TOO_COMPLEX（UI 提示改小文件或先拆分）。
- **compare 窗口大文件渲染**：固定行高 + 可视窗口虚拟化 + 行文本分块拉取 + LRU 缓存；性能断言 C3 锁定。
- **合并写回安全**：始终 `.bak` + 原子写 + 撤销按钮；写回前校验冲突清零。
- **重命名两阶段回滚**：注入式测试保证回滚正确；`Exists` 判定用目录一次性扫描（防 TOCTOU 尽力而为）。
- **拆分流式**：`BufReader::read_until` + 每片 `write_atomic`；不做整文件内存读。
- **compare 窗口单例**：重复打开替换请求并聚焦（同 settings 先例）。
