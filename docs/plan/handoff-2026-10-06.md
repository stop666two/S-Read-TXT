## 六、环境与操作要点（防踩坑）

- 构建：`npm run tauri build -- --debug --no-bundle`（dev 语义 `cargo build` 不实测）；shell 需 `$env:PATH='D:\msys64\ucrt64\bin;'+$env:PATH`。
- 探针：显式 `SRT_DATA_DIR` 隔离；残留 `s-read-txt.exe` 会占单实例（启动前清场，按 PID 杀，禁 `taskkill /IM node.exe`）。
- 文本编辑一律用 edit/write 工具；禁止 PowerShell 改文本（UTF-8/BOM 损坏）；BOM 修复用 `[IO.File]::ReadAllText` + `WriteAllText(UTF8Encoding($false))`。
- 长任务：WMI `Win32_Process.Create` 后台启动（需 `cd /d`）+ 轮询日志；预计 >300s 必须后台。
- 测试真实断言原则：探针 `check()` 必须判定（禁只打印）；虚拟列表断言先滚到目标；负载下断言一律轮询至稳定。
