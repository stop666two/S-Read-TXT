## 3. 关键环境与工具链备忘

- **构建环境**：MSYS2 ucrt64 需在 PATH 前（Tesseract 旧 DLL 遮蔽问题）；`dev.mjs` 自带探测（`SRT_MSYS_BIN` 可覆盖）。`cargo test` 需 `src-tauri/target/debug` 入 PATH（WebView2Loader.dll），dev.mjs 已处理。
- **长任务**：WMI 分离启动 + 轮询（模板：`cmd.exe /c ...` 且含 `set "PATH=..."`）；bash 工具超时会杀子进程树（普通 Start-Process 不可靠）。日志路径用项目 `tmp/`。
- **E2E 模式**：`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<随机>` + CDP（`scripts/lib/smoke-cdp.mjs`：`findTarget/openPathDone/dismissOnboarding/waitForValue`）；菜单点击用真实鼠标事件；受控输入用 `Input.insertText`（合成事件不驱动 Svelte 绑定）；`evalJs` 需 `awaitPromise:true`。
- **测试数据**：`scripts/lib/system.mjs`（makeBigFile 等）；测试用 `SRT_DATA_DIR` 指向临时目录；UI 截图由套件写入 `docs/screenshots/`。
- **已知坑（务必避免重蹈）**：
  - Svelte 生成锚点注释会出现在 `{#each}` 等子节点首位（`.txt` firstChild 不是 Text）→ 文本节点遍历用 TreeWalker；行模板保持**单行零空白**（多行缩进会污染 textContent）。
  - `toasts.show('key')` 必须 `toasts.show(t('key'))`；`toIpcError()` 返回 payload，`describeIpcError(payload)` 返回 string。
  - filesystem 编辑工具的 `replaceAll` 只替首处；多文件批改优先用临时 Node 脚本（项目 `tmp/`，用后即删）。
  - PowerShell `Set-Content -Encoding UTF8` 会写 BOM——改文本文件用 `UTF8Encoding($false)` 或 edit 工具。
  - `$PID` 是 PS 只读变量；按名杀 `msedgewebview2` 会伤及其他应用（只 `taskkill /PID <本应用> /T /F`）。
  - 会话恢复/自动滚动等"程序化滚动"与用户滚动需区分（`markUserInput` 门控已有先例）。
  - 分屏（spread）渲染只用 `.spread` 绝对定位方案（百分比高度会塌陷）。
  - Tauri 同步命令内 `run_on_main_thread` 会自锁（打印功能已改 `async fn`，勿回退）。
  - 单实例插件必须**首位注册**；命令参数清洗在 `cli.rs::file_args`（可单测）。
  - `cargo build`（非 tauri CLI）会覆盖 exe 为 dev 语义（localhost:1420）——冒烟前必须 `dev.mjs build`。
