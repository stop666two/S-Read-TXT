## 一、未开始的功能阶段（已确认规划）

### P1 编辑批量核心
- 批量插入/序号（10 种格式、模板变量、范围选择、预览、异步分片、单撤销步）——设置规格 E 组
- 常用行操作 30+（排序/去重/缩进/大小写/列编辑等）——L 组
- 多光标（列/矩形选择）、剪贴板历史（含复制格式）
- 过滤视图（编辑期按正则/条件隐藏行；仅视图不改内容）
- 查找替换增强（多文件搜索替换）
- 参考：设置规格 §2–§5；阶段计划 P1

### P2 阅读增强
- 状态栏 v2（字素簇/码点/字节计数、可配置元素与顺序、点击跳转行列）
- 大纲/折叠/面包屑（正则可编辑、编辑+阅读双模式）
- 书签与高亮（持久化到数据目录、锚点跟随编辑）
- 阅读模式组（专注/打字机/自动滚动/分页/双页/动画）
- 提醒与统计（护眼提醒/番茄钟/阅读时长）
- 参考：设置规格 §6、§8、§9；阶段计划 P2

### P3 文件与流程
- 自动保存快照 + 崩溃恢复 + 版本历史（份数+容量双上限）
- 导出（文本类）/打印 PDF；新建文件；文件关联与打开方式
- 多窗口 + 分屏（≤4 栏，跨窗口拖拽）
- 比较/合并/拆分/重命名
- 会话恢复扩展（光标/折叠状态等）
- 参考：设置规格 §7；阶段计划 P3

### P4 系统与发布
- 命令面板；可访问性全量（高对比叠加/减少动画/字体缩放/屏幕阅读器）
- 性能模式、隐私清除（一键清理本地各类数据）
- 手动检查更新（GitHub Releases，应用内下载+SHA256，失败降级）
- 全量验收与发布演练
- 参考：设置规格 §10–§14；阶段计划 P4
