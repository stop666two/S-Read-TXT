## 任务 5：手动更新检查（可配置 URL + 桩测试）

**Files:**
- Create: `src-tauri/src/update.rs`（检查/下载/校验）
- Modify: `src-tauri/Cargo.toml`（`ureq` + `sha2`，锁定版本；MIT/Apache 许可）
- Modify: `src-tauri/src/commands.rs` + `main.rs`（`check_update`、`download_update`、`reveal_file`、`open_release_page`）
- Modify: `src/windows/settings/`（系统页：sourceUrl 输入行 + 「检查更新」ActionRow + 结果对话框）
- Modify: `src/lib/i18n/*`、`docs/configuration.md`

**行为：**
- sourceUrl 空 → 按钮禁用+提示「未配置更新源」。接受 GitHub 仓库 URL（转 `https://api.github.com/repos/<o>/<r>/releases/latest`）或直连 JSON URL。
- `check_update(url)`：HTTP 超时 10s，解析 `tag_name`/`assets[]`/`digest`；与 `CARGO_PKG_VERSION` 比较（数字段对比 + prerelease 简单规则）；返回 `UpdateInfo{available,version,notes,assets[{name,url,size,sha256?}],pageUrl}`。
- offlineMode 开 → 前端先弹确认「将访问网络，是否继续？」；取消则零请求。
- `download_update(url, sha256, name)`：流式下载到数据目录 `updates/`，边下边算 SHA-256；与 API digest 比对（无 digest → 返回警告并保留文件）；失败/校验不过 → 删除残件 + 错误。
- 失败降级：任何错误 → 对话框显示原因 + 「打开发布页」/「复制链接」。
- 「打开所在文件夹」用 `explorer /select`（Rust `std::process::Command`，Windows 限定）。

**步骤：**
1. Cargo.toml 加依赖（精确版本）；`update.rs`：版本比较（5 用例）、digest 解析、URL 归一（GitHub→API）；单测。
2. 命令 + 前端对话框流；本地桩：node 静态服务器（`scripts/lib/stub-update-server.mjs`）返回 release JSON + 文件（`http://127.0.0.1:port`）。
3. 探针 `tmp/probe-update.mjs`：成功（下载+SHA256 通过）、校验失败降级、离线确认两态、未配置禁用；截图。
4. 提交。
