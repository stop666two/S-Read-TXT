## P0-1 大文件双阈值

**目标**：`maxFileSizeMB` 语义拆分为只读阈值（默认 100MB）+ 硬上限（默认 2048MB）。文件 > 只读阈值且 ≤ 硬上限 → 以只读模式打开并提示；> 硬上限 → 拒绝并提示（沿用逐字文案）。

**文件**
- 修改：`src-tauri/src/settings/model.rs`（AppSettings 增加 `hardLimitMB`，默认 2048，范围 128–16384；`maxFileSizeMB` 更名语义为只读阈值，保留字段名以兼容）
- 修改：`src-tauri/src/settings/defaults.rs`（`DEFAULT_HARD_LIMIT_MB=2048`、`HARD_LIMIT_RANGE=(128,16384)`）
- 修改：`src-tauri/src/settings/store.rs`（normalize 钳制 hardLimit）
- 修改：`src-tauri/src/textfile/session.rs`（`FileSession::open` 返回 `OpenMode::ReadOnly | ReadWrite` 或新错误 `TooLargeForHardLimit`）
- 修改：`src-tauri/src/app_state.rs`（打开时按阈值决定 `editing` 可用性：超只读阈值时 `toggle_edit` 拒绝并附文案）
- 修改：`src-tauri/src/commands.rs`、`src-tauri/src/ipc_error.rs`（新错误码）
- 修改：`src/lib/ipc.ts`、`src/lib/state/tabs.svelte.ts`（只读提示 toast）、`src/windows/settings/GeneralTab.svelte`（双输入）

**接口**
```rust
pub enum OpenPolicy {
    ReadWrite,
    ReadOnly { reason: String },
}
pub fn classify_size(size: u64, read_limit_mb: u32, hard_limit_mb: u32) -> Option<OpenPolicy>
// None = 超出硬上限（拒绝）
```

**测试**（单测）
- 边界：`size == read_limit` → ReadWrite；`+1` → ReadOnly；`size == hard_limit` → ReadOnly；`+1` → None。
- normalize：hardLimit 钳制与非法值回退。
- E2E（smoke 扩展）：构造 101MB 文件 → 打开后编辑按钮禁用 + toast 文案；构造超硬上限配置（设置里把硬上限调低到 128MB）→ 打开 200MB 文件被拒。

**验收**：双阈值行为正确；编辑入口在只读模式禁用且有说明；现有 100MB 场景回归通过。
