# S-Read-TXT 实施计划

- 依据：`docs/design/2026-10-02-s-read-txt-design.md`（定稿基线 v1.0）
- 执行规则：每阶段 = 实现 → 实际运行验证（截图 + 日志）→ 用户确认 → `git commit`（Conventional Commits，`feat(ai):` / `fix(ai):` / `chore(ai):`）
- 高风险前置：编辑引擎排在阶段 3/4，尽早暴露，避免后期返工
- 每阶段完成定义：验收标准达成 + lint/typecheck/test 通过 + 文档同步 + 变更摘要

## 依赖关系

```
阶段0 ──► 阶段1 ──► 阶段2 ──► 阶段3 ──► 阶段4 ──► 阶段5 ──► 阶段6 ──► 阶段7 ──► 阶段8 ──► 阶段9
                   （阅读界面）  （编辑后端）（编辑交互）（多标签）（历史）（快捷键）（设置/会话）（测试打包）
```

## 阶段 0：工程初始化

- [ ] `git init`；`.gitattributes`（`* text=auto eol=lf` + 二进制声明）
- [ ] `.gitignore` 追加：`src-tauri/target/`、`src-tauri/gen/`、`data/`
- [ ] LICENSE（MIT，`Copyright (c) 2026 stop666two`）、README.md、CHANGELOG.md（Keep a Changelog）
- [ ] pre-commit 钩子（`core.hooksPath=scripts/git-hooks`）：拦截 AGENTS.md 变体与 `data/` 路径
- [ ] 前端脚手架：package.json（精确版本）、vite/uno/svelte/ts/vitest 配置、index.html、最小 App
- [ ] Rust 脚手架：Cargo.toml（`=` 精确版本）、build.rs、tauri.conf.json（NSIS、WebView2 skip、CSP、单窗口 1100×760 最小 720×480、identifier `com.sreadtxt.app`）、capabilities（core:default + dialog:default + 创建设置窗口）
- [ ] 图标：`scripts/make-icons.mjs` 生成 1024 PNG → `tauri icon` 生成全套
- [ ] `scripts/check-encoding.mjs`（UTF-8 无 BOM、LF 检查）
- [ ] `npm install` + `cargo build`（首编 ~12min，后台 + 轮询）
- **验证**：空壳可启动；`npm run build`、`cargo build` 通过；编码自检通过
- **提交**：`chore(ai): 工程初始化（Tauri2+Svelte5 脚手架、便携数据目录保护）`

## 阶段 1：Rust 核心（无 UI）

- [ ] storage：便携路径解析、可写探测、原子写（tmp+rename）、`SRT_DATA_DIR` 覆盖
- [ ] settings/reader/shortcuts 三类配置模型 + 默认值 + 校验 + 原子读写
- [ ] history.jsonl 追加/去重/剪枝（条数+天数）
- [ ] session.json 读写（窗口状态 + 标签锚点）
- [ ] textfile：mmap、编码检测+解码窗、稀疏块索引、行↔偏移映射、8KB 显示行分块
- [ ] logging：JSON 行 + 轮转 + 级别开关
- [ ] 单元测试 + 集成测试（不开窗口）
- **验证**：`cargo test` 全绿；生成多编码/多换行/大文件样本（`scripts/`）自测
- **提交**：`feat(ai): Rust 核心（mmap/编码/稀疏索引/存储/历史/会话）`

## 阶段 2：阅读界面

- [ ] 虚拟滚动渲染（DOM 复用、高度缓存、预取、单请求在途）
- [ ] 菜单栏/工具栏/状态栏骨架、主题系统（4 主题 + CSS 变量）、排版设置应用
- [ ] 打开文件（对话框）、拖拽打开、编码点击切换、超限逐字文案、空状态、Toast
- [ ] 每标签滚动状态保持（内存中）
- **验证**：真实运行截图（浅/深/护眼）、滚动 100MB 文件流畅、编码切换正确
- **提交**：`feat(ai): 阅读界面（虚拟渲染/主题/菜单工具栏/状态栏）`

## 阶段 3：编辑引擎 A（片表后端）【最高风险，前置】

- [ ] piece table + Fenwick 行数索引 + 行↔偏移映射（含编辑后）
- [ ] apply_edits / undo / redo（50MB/1000 步双上限）
- [ ] 保存链：编码询问流、字节直拷 vs 转码、.bak 首存、原子写、外部冲突检测、另存为
- [ ] 单测：插入/删除/跨块/撤销重做/保存一致性（保存后重读 == 内存视图）
- **验证**：命令行级集成测试 + 与样本文件回读校验
- **提交**：`feat(ai): 编辑引擎后端（片表/撤销/保存链）`

## 阶段 4：编辑引擎 B（编辑交互层）

- [ ] 只读↔编辑切换；脏标记；未保存关闭确认（标签/窗口）
- [ ] 光标/选区（点击/拖选/Shift+方向键/全选）、输入/删除/回车
- [ ] IME 隐藏锚点（中文拼音组合输入）——专项测试
- [ ] 剪切/复制/粘贴（大范围复制确认）
- [ ] 查找/替换（大小写开关、下一个/替换/全部替换）
- **验证**：中文输入法实测录屏/截图；编辑-保存-重开一致性；外部修改冲突流
- **提交**：`feat(ai): 编辑交互层（光标/IME/撤销/查找替换）`

## 阶段 5：多标签

- [ ] 紧凑矩形标签栏（关闭常显、中键关闭、右键菜单：关闭/关闭其他/关闭全部）
- [ ] 拖拽排序、溢出滚动、上限（默认 20，可设，超限 Toast）
- [ ] 切换保持滚动/编辑态/脏标记；重复打开激活已有标签
- **验证**：20 标签压测、拖拽排序截图
- **提交**：`feat(ai): 多标签（排序/右键/上限/状态保持）`

## 阶段 6：历史记录

- [ ] 独立面板（虚拟列表、搜索、单条删除、清空）

## 阶段 7：快捷键

- [ ] 设置窗口（独立、五页签、全部配置项、即时生效、文件大小上限/标签上限/历史保留/排版/主题）
