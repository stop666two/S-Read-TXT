# 已知问题与限制

> 本文件随开发推进持续更新；发布时自动纳入 Release 描述（`scripts/ci/release-notes.mjs`）。
> 最后更新：2026-10-02（发布前整理）

1. **未进行代码签名**：首次运行时 Windows SmartScreen 可能提示「未知发布者」。请核对 Release 中的 SHA256 校验和后再选择「仍要运行」。
2. **不支持 Windows 7 / 8.1**：微软已于 2023-01 随 Edge/WebView2 109 终止对这两代系统的支持（此后无安全更新）；且本程序工具链（Rust 自 1.78 起最低要求 Windows 10）无法为 Win7 产出受支持的可运行二进制。支持范围：Windows 10 1803+。
3. **内存映射的文件占用**：已打开的文件以内存映射（mmap）方式持有。第三方程序若以「就地在原文件修改」的方式写入，会被系统拒绝（`ERROR_USER_MAPPED_FILE`，错误码 1224）；采用「临时文件 + 原子替换」方式保存的编辑器不受影响（本程序保存即此路径）。
4. **32 位（x86）版本定位**：面向旧设备，超大文件（接近 100MB 上限）场景下内存与性能表现弱于 64 位版本，建议优先使用 x64。
5. **内存红线口径**：验收口径为「10 个标签的只读阅读态、设置窗口关闭」的进程树专用工作集合计；实测构成与数值见测试报告（逐变体明细 JSON 位于 `docs/verify/`）。
6. **旧版本获取方式**：Releases 只保留最新一个（发布新版本时会删除其他全部旧 Release），旧版本源码可通过对应 tag（永不删除）获取并自行构建。
7. **测试覆盖持续补充**：测试项随开发持续增加；当前覆盖情况见每次发布附带的 `test-summary.md`。
