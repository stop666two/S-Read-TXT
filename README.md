# S-Read-TXT

极简 Windows 桌面 TXT 阅读器（可切换编辑）。基于 Tauri v2 + Rust + Svelte 5，完全离线、便携存储、专注长文阅读。

[![CI](https://github.com/stop666two/S-Read-TXT/actions/workflows/ci.yml/badge.svg)](https://github.com/stop666two/S-Read-TXT/actions/workflows/ci.yml)

- 版本：0.0.1-beta
- 平台：Windows 10/11（x64 / x86 32 位 / ARM64 三架构构建）
- 许可证：MIT
- 仓库地址：https://github.com/stop666two/S-Read-TXT

## 功能

- 阅读：内存映射 + 按需分页读取（禁止整读文件），支持超大文件（默认上限 100MB，可设置）；自动检测编码（BOM/chardetng）并可手动切换；兼容 LF/CRLF/CR 与无换行超长行
- 多标签：紧凑标签栏（中键关闭、右键菜单、拖拽排序、上限可设），切换保持各标签阅读状态
- 历史记录：独立面板 + 菜单「最近打开」，重开恢复阅读进度；条数与保留期可设，支持清理
- 快捷键：应用内全局、默认方案 + 自定义（录制、冲突检测、恢复默认）
- 编辑（可选切换）：分块编辑引擎（piece table），任意大小文件、内存随编辑量增长；查找替换、另存为、首存 .bak、保存编码询问
- 主题：浅色 / 深色 / 护眼 / 跟随系统；排版（字号/行距/字体/限宽/边距）可调

## 系统要求

- **Windows 10 1803 及以上**（x64 / x86 / ARM64 三架构构建）；依赖系统 WebView2 运行时（Windows 10/11 通常已预装；缺失时可用微软官方 Evergreen 安装包离线安装）
- **不支持 Windows 7 / 8.1**：微软已于 2023-01 随 Edge/WebView2 109 终止对这两代系统的支持（此后无安全更新）；同时本程序工具链（Rust 自 1.78 起最低要求 Windows 10，构建目标 `x86_64-pc-windows-gnu` 在列）无法为 Win7 产出受支持的可运行二进制。详见 `docs/known-issues.md`

## 发布与 CI/CD

- **CI**（`.github/workflows/ci.yml`）：任意分支 push / PR 触发——仓库卫生检查（AGENTS.md 防泄露、便携数据目录、大文件）、编码与换行自检（UTF-8 无 BOM / LF）、前端检查测试构建、Rust 全量测试与完整构建（含 `cargo fmt` 检查）、32 位与 ARM64 兼容检查
- **发布**（`.github/workflows/release.yml`）：仅 tag（`v*`）触发；三架构（x64 / x86 / ARM64）NSIS 安装包；描述包含测试摘要、构建环境、变更明细、SHA256 校验和、**安装范围与启动权限行为说明**、已知问题与备份提醒
- **Releases 只保留最新一个**：发布新版本时，其他全部旧 Release（含测试版与正式版）被删除；**tag 永不删除**，旧版本可经对应 tag 获取源码自行构建
- tag 名含 `-`（如 `v0.0.2-beta`）自动标记为预发布（prerelease）
- CI 与发布构建使用 MSVC 工具链；本地开发可继续使用 GNU（见上节说明）

## 开发环境要求

- Windows 10/11 x64，WebView2 运行时（系统自带；安装包不捆绑）
- Node.js ≥ 20（开发使用 v26）与 npm
- Rust 工具链（本地开发使用 stable-x86_64-pc-windows-gnu；CI 与发布构建使用 MSVC）

### Windows 构建环境注意

- 首次 Rust 编译约需 10~15 分钟（依赖全量编译），之后增量构建为秒级。
- 本项目在 Windows 上以 **GNU 工具链**实测构建通过（Tauri 官方仅支持 MSVC；如需切换：安装 VS Build Tools 后执行 `rustup default stable-x86_64-pc-windows-msvc`）。
- 若构建报 `windres: preprocessing failed.` 或 `cc1.exe` 静默失败（退出码 `0xC0000139` / `STATUS_ENTRYPOINT_NOT_FOUND`）：原因是 PATH 中其他目录（如 Tesseract-OCR）携带的**旧版 `libgcc_s_seh-1.dll`** 抢先覆盖了 MSYS2 的运行库。修复：确保 MSYS2 的 `ucrt64\bin`（以你机器上的实际安装位置为准）在 PATH 中排在该目录之前，或从 PATH 移除该目录后重新构建；自检脚本可用环境变量 `SRT_MSYS_BIN` 指定该目录（未设置时自动从 PATH 探测）。
- **「localhost 拒绝连接」防护（已根治）**：Tauri 以 `custom-protocol` feature 区分打包模式（内嵌前端资源）与开发模式（连 `http://localhost:1420`）；`tauri build` 由 CLI 自动启用，而裸 `cargo build`/`cargo test` 不会——产物会显示「localhost 拒绝连接」。本项目已在 `Cargo.toml` 中**常开该 feature**，任何方式编译的 exe 均可独立运行。代价：不支持 `tauri dev` HMR 开发服务器（本项目流程为构建产物 + CDP 自动化验证，不使用）。

## 数据与隐私

- 强制便携模式：所有数据存放于**程序目录** `data/`（`settings.json`、`reader.json`、`shortcuts.json`、`session.json`、`history.jsonl`、`logs/`），不写入系统其他位置（`SRT_DATA_DIR` 覆盖与「数据目录引导」的会话级重定向除外，见下节）
- **不写注册表、不写系统环境变量**（应用本体；「所有用户」安装的卸载信息登记除外，卸载时自动清理）；可整体复制到 U 盘或其他电脑继续使用
- 完全离线：无遥测、无错误上报、无更新检测、无任何网络请求（WebView2 启动参数已禁用后台联网/组件更新/同步）
- 数据不加密；日志不含敏感内容

## 安装与权限行为

### 两种形态任选：便携版（zip）/ 安装版

| 形态 | 获取 | 使用方式 | 卸载 |
|---|---|---|---|
| **便携版（推荐）** | Release 资产 `S-Read-TXT_<版本>_<架构>-portable.zip` | 解压到任意可写目录（本地磁盘 / U 盘均可），双击 `s-read-txt.exe` 即用；数据全部写在同目录 `data/`；整个文件夹可随时复制到其他电脑 | 删除文件夹 |
| **安装版** | Release 资产 `...-setup.exe`（NSIS） | 向导安装（范围二选一，见下节）；**安装后的目录同样自包含，可直接整体复制到另一台电脑使用** | 「应用和程序」卸载（或删除文件夹） |

> 应用本体**不写注册表、不写系统环境变量**（安装版仅在注册表登记「卸载信息」以便正常卸载，卸载时自动清理）。

### 安装向导：两种安装范围二选一

| 选项 | 安装位置 | 权限要求 | 适合场景 |
|---|---|---|---|
| **为本机所有用户安装** | `C:\Program Files\S-Read-TXT` | 需要管理员权限（选择此项时安装器会请求 UAC） | 多用户共用一台机器 |
| **只为我自己安装** | `%LOCALAPPDATA%\S-Read-TXT` | 不需要任何权限 | 个人使用（推荐，启动无任何权限提示） |

### 程序启动时的权限行为（自动、按需）

程序坚持便携模式（数据写在程序目录 `data/`），因此**只在数据目录确实不可写时才请求管理员权限**：

| 场景 | 行为 |
|---|---|
| 便携运行（数据目录可写） | 不请求任何权限 |
| 「仅为我」安装（`%LOCALAPPDATA%`，可写） | 不请求任何权限 |
| 「所有用户」安装（`Program Files`，标准用户） | **首次启动请求一次管理员权限（UAC）**：仅用于「创建数据目录 + 授予当前用户修改权限」（提权助手完成即退出）；应用本体始终以普通权限继续运行，完成后再无提示；**取消**后进入「数据目录引导」，可选择其他可写目录（本次运行有效）或只读运行 |
| 已提权启动（手动以管理员运行等） | 就地完成一次幂等授权，保障 WebView2 子进程可写数据目录 |
| 设置了 `SRT_NO_ELEVATION=1` | 跳过提权初始化，按不可写流程进入「数据目录引导」 |

补充说明：

- 管理员权限只用于一次权限初始化，不用于运行应用本体——WebView2 等子进程始终以普通权限运行，不受提权影响；
- 授权对象固定为发起应用的当前用户（SID 由程序自身计算后交给助手；即使 UAC 弹窗中输入其他管理员凭据也不改变）；同机其他用户各自首次启动授权一次；
- 为什么需要：程序坚持便携模式（数据写在程序目录），标准用户无法写 `Program Files`；不授权则 WebView2 无法读写程序目录下的数据目录（曾导致启动失败）；
- 不想看到 UAC：请选择「仅为我」安装或便携使用。

## 多窗口与标签

- **新建窗口**：快捷键 `Ctrl+Shift+N`、标签栏右侧「新建窗口」按钮或菜单「文件 → 新建窗口」；每个窗口拥有**独立的标签组与独立会话**——下次启动会恢复窗口数量、各自位置与标签（受「启动 → 恢复上次会话」开关控制）；
- **标签颜色**：右键标签 →「颜色」选 8 色之一（红/橙/黄/绿/青/蓝/紫/灰）或清除；以标签左侧色条呈现，深浅主题自动换用对应亮度，随会话持久化；
- **跨窗口移动标签**：右键标签 →「移动到窗口 → 目标窗口」（目标已打开同一文件时合并并激活）；也可直接**拖动标签到另一窗口**——拖影跟随光标、目标窗口显示插入位置指示，拖到桌面空白处会**新建窗口**承载该标签；拖拽中按 `Esc` 取消，拖回源窗口按落点精确插入；
- 多窗口共享同一进程与数据目录；关闭单个窗口仅影响该窗口的标签，关闭最后一个窗口才退出程序并写入「干净退出」标记。

## 窗口内分屏与栏位

- **分屏**：窗口最多切分 4 栏（菜单「查看 → 向右拆分 / 向下拆分」、`Ctrl+\` / `Ctrl+Shift+\`，或标签栏右侧拆分按钮）；拖标签到某栏内容区**边缘**亦可就地分屏；每栏拥有**独立标签组**，标签可拖拽在栏间移动（拖到标签条按位置插入、拖到内容区居中并入栏尾）；
- **关闭栏位**：`Ctrl+Shift+W` 或标签栏「关闭栏位」按钮——栏内标签**无损并入相邻栏**后收起该栏；唯一栏时不可关闭；
- **分隔条**：拖动调整各栏比例随会话恢复；
- **会话 v3**：`session.json` 记录每窗的栏位树（方向/比例）、每栏标签与激活项、聚焦栏；旧 v1/v2 会话自动迁移为单栏。

## 工具（拆分 / 批量重命名 / 比较 / 三方合并）

菜单「工具」提供四个数据整理功能；对话框中的源文件与输出目录均为可编辑输入框，也可用「…」按钮调用系统文件/目录选择器。

- **拆分文件…**：两种模式——按行数每 N 行一片，或按标记切割（匹配行归下一片；纯文本包含匹配或正则）；输出名 `原名-0001.txt` 自动编号，输出目录缺省为源目录；先预览分片数与覆盖风险再执行，可一键打开第一份；
- **批量重命名…**：扫描目录（扩展名白名单，缺省 txt/log）或使用已打开标签；规则可组合：查找替换（茎部）、前缀、后缀、插入序号（起始/步进/位数/前置或后缀）；预览列表标注冲突（目标重名）/已存在/非法名/未变；执行采用两阶段改名防冲突，**内置撤销**恢复上一次批量操作；
- **比较文件…**：选择两个文件打开独立**比较窗口**；并排双栏（行号对齐、差异行着色）与统一视图（+/- 行内嵌）一键切换，支持「上一处/下一处」导航；大文件按可见区域懒加载；
- **三方合并…**：一次选择 底本 → 我方 → 他方；自动合并无冲突改动，冲突逐块选择 **我方 / 他方 / 双方 / 不用**（未选择时默认我方）；写回默认目标为我方文件，写回前自动生成 `<文件名>.bak` 备份，可**撤销写回**；比较/合并均不要求文件已打开，编辑中标签请先保存再比较。

## 命令行与文件关联

### 命令行打开文件

```powershell
s-read-txt.exe <文件路径> [更多文件…]
```

- 参数中**存在的普通文件**会在启动时依次打开为标签；开关参数（以 `-` 开头）、目录与不存在的路径自动忽略，重复路径去重；
- 程序**单实例运行**：若已有窗口在运行，第二次启动会把文件参数转发给现有窗口（新增标签）并立即退出，不会打开第二个窗口；
- 菜单「文件 → 打开剪贴板中的路径」：读取剪贴板文本的**首行**（去空白）作为路径打开，便于从聊天记录/终端复制路径后直接打开。

### 文件关联（双击打开）

- **安装版**：安装程序会把 `.txt` 与 `.log` 的默认打开方式设为本程序（安装时备份原默认值，卸载时自动恢复）；
- **便携版**：为保持「不写注册表」的便携语义，不自动注册关联，需手动设置——右键任意 `.txt` 文件 →「打开方式」→「选择其他应用」→「更多应用」→「在这台电脑上查找其他应用」→ 选择 `s-read-txt.exe` → 勾选「始终使用此应用」；
- 设置项 `file.associations` 当前为偏好记录；安装器的实际注册范围以 `tauri.conf.json` 的 `bundle.fileAssociations` 为准（当前 `.txt` / `.log`，随下一次安装包构建生效）。

## 环境变量（可选）

| 名称 | 用途 | 类型 | 必填 | 示例 |
|---|---|---|---|---|
| `SRT_DATA_DIR` | 覆盖数据目录（便于测试与特殊部署） | 路径字符串 | 否 | `D:\srt-data` |
| `SRT_LOG_LEVEL` | 覆盖日志级别（error/warn/info/debug） | 枚举字符串 | 否 | `debug` |
| `SRT_NO_ELEVATION` | 跳过启动时的提权初始化（存在即生效；不想看到任何 UAC 时使用） | 开关（存在即启用） | 否 | `1` |
| `SRT_MSYS_BIN` | 仅自检脚本（`scripts/verify-all.mjs`）使用：MSYS2 `ucrt64\bin` 目录；未设置时自动从 PATH 探测以 `ucrt64\bin` 结尾的条目（CI 无需） | 路径字符串 | 否 | 按实际安装位置 |

说明：应用不读取 `.env` 文件，环境变量由启动环境（终端/快捷方式）提供。
